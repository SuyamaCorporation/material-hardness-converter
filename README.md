# Material Hardness Scale Converter

**Category:** Engineering & Materials Science Tools

Convert between Mohs, Rockwell C (HRC), Rockwell B (HRB), Brinell (HBW), Vickers (HV), and Shore D hardness scales using ASTM-standard polynomial approximations. Includes a 25+ material reference database covering minerals, steels, metals, and polymers with real-world applications. Visual scale bars show where values fall on each scale. Searchable material table with one-click lookup.
